Adágún tí a gbàlejò fúnra wa ń ṣiṣẹ́ lórí ẹ̀rọ **.113** (`tomni-proxmox-113`). Láti 2026-10-18, runner
OmniRoute kọ̀ọ̀kan ní **ipa kan**, label kan, àti ìpín memory/CPU tí a ṣe déédé pẹ̀lú ohun tí a díwọ̀
fún iṣẹ́ rẹ̀. Ààyè Turbopack ń gba ohun tí ìkọ́lé náà nílò; àwọn ààyè yòókù sì ní ìwọ̀n tó bá
àwọn òkè ìlò tí a díwọ̀ mu. Ẹ̀rọ náà kàn máa ń pín ohun àmúṣagbára ju èyí tó wà lọ nígbà tí ìkọ́lé Turbopack bá bá ìkọ́lé webpack
Release-Green àti iṣẹ́ lint kan ṣẹlẹ̀ lẹ́ẹ̀kan náà; swap host (16 GB) ń gba èyí, àti nítorí pé àwọn ìkọ́lé pull-request ń ṣiṣẹ́
lórí hosted, ààyè Turbopack kì í ṣiṣẹ́ ní ọ̀pọ̀ jù lọ àkókò:

| runner               | label           | ipa                                                                                                                                               | `MemoryHigh` / `MemoryMax` | `CPUQuota`   |
| -------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ------------ |
| `omniroute-113-5`    | `omni-build`    | Àwọn ìkọ́lé Turbopack: `ci.yml` `Build` (push/dispatch nìkan), Docker amd64, `npm-publish`, `nightly-v4-build`, `preview-artifact`, ìkọ́lé a11y alẹ́ | 56 GB / 60 GB (swap 0)     | 1600 %       |
| `omniroute-113-6`    | `omni-release`  | Release-Green (`release-green` + `main-green`), ìkọ́lé webpack                                                                                     | 20 GB / 24 GB (swap 4 GB)  | 800 %        |
| `omniroute-113-2`    | `omni-light`    | àwọn iṣẹ́ alẹ́ (Schemathesis, promptfoo, garak, k6, ìbẹ̀rẹ̀ a11y) àti `quality.yml` `lint-guard`                                                      | 12 GB / 16 GB (swap 4 GB)  | 600 %        |

| ohun àmúṣagbára | iye                        | ohun tí ó túmọ̀ sí fún ṣíṣe ètò iṣẹ́                                                                                                                                                                                                                                                                                                                                      |
| --------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RAM / CPU       | **78 GB / 32 cores**       | ìkọ́lé production Turbopack kan dé òkè 49 GB láìsí ààlà (`tests/unit/ci-build-bundler-webpack.test.ts`); lórí Next 16.3.8, ìpele compile nìkan ń di ~40 GB mú (36 GB RSS nínú `next-build` pẹ̀lú loader workers 17 ní 3 GB, tí a díwọ̀ ní 2026-10-18); ìkọ́lé webpack kan wà ní ~14–16 GB. Turbopack kan + ìkọ́lé webpack kan lè ṣiṣẹ́ pọ̀; ìkọ́lé Turbopack méjì kò lè ṣiṣẹ́ pọ̀ |
| swap            | 16 GB                      | `omniroute-113-5` ń ṣiṣẹ́ láìsí swap (`MemorySwapMax=0`) kí ìkọ́lé tó sá kọjá ààlà lè dá ní cap rẹ̀ dípò kó jẹ́ kí ẹ̀rọ náà bẹ̀rẹ̀ sí í lo swap                                                                                                                                                                                                                                |
| `/tmp`          | **12 GB tmpfs = RAM**      | ohunkóhun tí a bá fi síbẹ̀ jẹ́ memory; a máa ń nu àwọn ohun tó ṣẹ́ kù lẹ́yìn 3 h                                                                                                                                                                                                                                                                                            |
| CPU             | a rí load 60 lórí 32 cores | ṣáájú àwọn quota náà, ìkọ́lé Turbopack kan (~1166 % CPU) pẹ̀lú coverage suite kan lórí ẹ̀rọ kan náà kò jẹ́ kí heartbeat àwọn listener yòókù rí ohun àmúṣagbára tó (`The self-hosted runner lost communication`, #16853)                                                                                                                                                     |
| runners         | **6 listeners**            | OmniRoute 4 + OmniHeuris + OmniMind; `omniroute-113-3/-4/-7/-8` jẹ́ disabled (`systemctl enable --now` máa ń mú ọ̀kan padà)                                                                                                                                                                                                                                               |

Àwọn ààlà náà wà nínú `/etc/systemd/system/actions.runner.<…>.service.d/override.conf` ti unit kọ̀ọ̀kan
(a pa àwọn iye àtijọ́ mọ́ gẹ́gẹ́ bí `override.conf.bak-20261018`) a sì lò wọ́n ní tààrà pẹ̀lú
`systemctl set-property --runtime … MemoryHigh=… MemoryMax=… CPUQuota=…` — kò sí restart, nítorí náà kò sí
iṣẹ́ tó ń lọ lọ́wọ́ tí a fọwọ́ kàn. A máa ń yí àwọn label padà nípasẹ̀ API àwọn runner
(`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`), ní tààrà bákan náà.

## Fi olùtọ́jú sori ẹrọ (lẹ́ẹ̀kan ṣoṣo, lórí ẹ̀rọ náà)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): ní gbogbo ìṣẹ́jú 30, kọ àkọsílẹ̀ sí /var/log/runner-janitor.log
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

`lsof` jẹ́ dandan: olùtọ́jú náà máa ń fi snapshot kan ṣoṣo ti àwọn fáìlì tí ó ṣí sílẹ̀
jẹ́rìí pé path kan kò ṣiṣẹ́ kí ó tó yọ ọ́ kúrò, àti pé láìsí irinṣẹ́ náà kò ní yọ ohunkóhun
kúrò, yóò sì sọ bẹ́ẹ̀ (exit 1). Kọ́kọ́ dán gbogbo àyípadà wò pẹ̀lú `--dry-run` — ó máa tẹ ohun
tí yóò ṣe gan-an jáde, kò sì ní fọwọ́ kan ohunkóhun.

Ohun tí ó máa ń ṣe ní gbogbo ìgbà tí ó bá ṣiṣẹ́: ó máa ń gba àwọn ohun tó ṣẹ́kù tiwa kúrò (`runner-*`, `omniroute-*`,
`next-build*`, `e2e-build.tar.gz`) lẹ́yìn **wákàtí 3 lórí tmpfs** àti wákàtí 24 lórí disk
`_work/_temp`; ó máa ń pa `next-build` tí ó ti ju ìṣẹ́jú 75 lọ (kò sí iṣẹ́ kankan tó máa ń ṣiṣẹ́ tó bẹ́ẹ̀ — ní
2026-08-27, ọ̀kan ṣiṣẹ́ fún ìṣẹ́jú 70 lẹ́yìn tí GitHub ti kéde pé iṣẹ́ rẹ̀ ti sọnù); ó máa ń gé àwọn
checkout ti àwọn runner tí ẹ̀ka wọn ti **dúró** tí wọ́n sì ti pé wákàtí 48 kúrò; ó máa ń fi ìkìlọ̀ ránṣẹ́ nígbà tí disk ≥ 85 %, PSI
ìrántí `full/avg60` ≥ 10 %, àti nígbà tí àwọn listener bá pọ̀ ju `MAX_ACTIVE_RUNNERS` lọ (pẹ̀lú
ìpín omniroute/òmíràn). Exit 1 = a nílò àkíyèsí; ka àkọsílẹ̀ náà.

Òfin ìṣẹ́jú 75 kò lè rí ìkọ́lé tí GitHub ti jáwọ́ nínú iṣẹ́ rẹ̀ tẹ́lẹ̀. Nígbà tí
`Runner.Listener` kò bá lè tún iṣẹ́ rẹ̀ ṣe, `_diag/Runner_*.log` máa ń fi
`POST request to …/renewjob timed out after 100 seconds` hàn, API máa ń sọ pé iṣẹ́ náà ti `completed`
(ìkùnà) ní nǹkan bí ìṣẹ́jú mẹ́wàá lẹ́yìn ìtúnṣe tó ṣàṣeyọrí kẹ́yìn, `next-build` sì máa ń bá iṣẹ́ lọ láìsí
iṣẹ́ tí a so mọ́ ọn (2026-10-18: ìkọ́lé #17066 kùnà ní 19:43, ìkọ́lé rẹ̀ sì ṣì ń
di 40 GB mú lẹ́yìn ìṣẹ́jú márùn-ún). Jẹ́rìí ref náà nínú `_diag/Worker_*.log` tuntun jù lọ, lẹ́yìn náà
fi SIGTERM pa igi ìkọ́lé náà nìkan nípa PID — `next-build`, `npm run build`, `build-next-isolated.mjs` àti
àwọn worker `_work`. Má ṣe fọwọ́ kan `Runner.Listener`, `RunnerService.js` tàbí `Runner.Worker` láéláé:
worker náà máa ń jabo pé a ti fagilé iṣẹ́ náà, listener náà sì máa ń padà sí online fúnra rẹ̀.

## Àwọn ẹ̀ka runner: KillMode

`KillMode=process` àìpé ti runner máa ń fi `Runner.Worker → npm → next-build`
sílẹ̀ láàyè nígbà tí a bá dá ẹ̀ka kan dúró tàbí tún un bẹ̀rẹ̀ — ìkọ́lé aláìní-olùtọ́jú máa ń bá a lọ láti jẹ RAM àti
CPU láìsí iṣẹ́ tí a so mọ́ ọn. Gbogbo ẹ̀ka OmniRoute ní fáìlì àfikún kan
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
pẹ̀lú `KillMode=mixed`: SIGTERM sí listener lákọ̀ọ́kọ́, lẹ́yìn náà SIGKILL sí gbogbo cgroup ní
`TimeoutStop`. Ó máa bẹ̀rẹ̀ sí í ṣiṣẹ́ nígbà tí a bá tún ẹ̀ka náà bẹ̀rẹ̀ — tún **runner kan ṣoṣo bẹ̀rẹ̀
lẹ́ẹ̀kan, nígbà tí kò bá ń ṣiṣẹ́ nìkan**, pẹ̀lú àyẹ̀wò pé kò ṣiṣẹ́ àti ìtún-bẹ̀rẹ̀ nínú àṣẹ kan náà.

## Àwọn òfin ìṣiṣẹ́

- **Ìkọ́lé Turbopack kan ṣoṣo lẹ́ẹ̀kan — a fi label mú un ṣẹ.** Gbogbo job tó ń ṣiṣẹ́ Turbopack
  `next build` kíkún ń lo `[self-hosted, omni-build]`, `omniroute-113-5` **nìkan** sì ni
  label yẹn: `ci.yml` `Build`, `npm-publish.yml` `publish`, `nightly-v4-build`, `preview-artifact`,
  ìkọ́lé a11y alẹ́ (#16853) àti `docker-publish.yml` **amd64** (webpack nínú BuildKit —
  Turbopack já níbẹ̀, run 33253576569). Ẹ̀ka Docker arm64 ṣì wà lórí `ubuntu-24.04-arm`.
  amd64 `docker-publish` ń lo concurrency group `heavy-build-main` kan náà pẹ̀lú `ci.yml` `Build`
  (`cancel-in-progress: false`). Docker Engine gbọ́dọ̀ wà lórí `omniroute-113-5`. Ààyè Turbopack
  kejì kò lè wọ 78 GB (2 × 33–37 GB pẹ̀lú ìyókù ẹ̀rọ náà); ààyè kejì jẹ́ àìléwu fún àwọn ìkọ́lé
  webpack nìkan.
- **Àwọn Build pull-request ń ṣiṣẹ́ lórí hosted (2026-10-18).** `ci.yml` `Build` dé `omni-build` nìkan fún
  `push` àti `workflow_dispatch`; gbogbo Build `pull_request` (láti orísun tirẹ̀ tàbí fork) àti
  `merge_group` ń ṣiṣẹ́ lórí `ubuntu-latest` pẹ̀lú webpack. Nígbà tí a darí gbogbo PR láti orísun
  tirẹ̀ sí ààyè náà, Build Turbopack kan máa ń dì í mú fún ìṣẹ́jú 29–58, Build 18 dúró ní queue
  fún tó wákàtí 18, Build push ti release line fúnra rẹ̀ sì rí ààyè náà lẹ́ẹ̀kan nínú job 40.
  Lórí hosted, Build PR kan náà máa ń gba ìṣẹ́jú 8–12 lẹ́gbẹ̀ẹ́ àwọn job PR yòókù. Turbopack,
  bundler tí `npm-publish` ń pín, ṣì ń gba ìdánwò lórí release line nípasẹ̀ ìkọ́lé a11y alẹ́ ti
  default branch (04:41 UTC), nípasẹ̀ gbogbo Build push tàbí dispatch tó dé ààyè náà, àti nípasẹ̀
  `npm-publish` fúnra rẹ̀. `tests/unit/build/heavy-build-queue.test.ts`
  fi gate oní-clause mẹ́rin náà múlẹ̀.
- **Má ṣe dín ààyè Turbopack kù ju ohun tí ìwọ̀n fi hàn pé ó nílò lọ.** Ní 2026-10-18 ní 18:06, a
  dín ààyè náà kù láti 56G/60G sí 40G/44G láti ṣe ààyè fún `omni-release`. Ìpele compile dúró ní
  `MemoryHigh` jálẹ̀ gbogbo run rẹ̀ (memory PSI `full` 30–43 %), `Runner.Listener`, tó ń
  lo cgroup kan náà, kò sì lè tún job rẹ̀ ṣe. A dá 56G/60G ti olówó rẹ̀ láti 2026-10-17 padà ní
  ọjọ́ kan náà. Ní ìsàlẹ̀ iye yẹn, ìkọ́lé náà kì í fail; ó máa ń tiraka léraléra, job náà sì máa ń sọnù.
- **Release-Green ní ààyè tirẹ̀ (2026-10-18).** Títí di ìgbà yẹn, àwọn validation Release-Green
  méjèèjì ń ṣiṣẹ́ lórí `omni-build`: ní gbogbo push (~10/wákàtí, 97 nínú run push 100 ni a
  cancel láàárín iṣẹ́ ní ọjọ́ kan) àti full sweep mẹ́ta tó fẹ́rẹ̀ẹ́ tó wákàtí 2 lójoojúmọ́
  (sweep 05:29 dúró fún wákàtí 6 de ààyè náà) — a béèrè iṣẹ́ ju agbára ààyè ìkọ́lé kan ṣoṣo náà
  lọ lọ́pọ̀lọpọ̀ ìgbà, àwọn Build PR láti orísun tirẹ̀ sì dúró fún ọ̀pọ̀ wákàtí.
  `release-green` àti `main-green` ń lo `omni-release` (`omniroute-113-6` nìkan) báyìí pẹ̀lú
  `OMNIROUTE_USE_TURBOPACK=0`, a kò sì cancel run tó ti bẹ̀rẹ̀ mọ́ nítorí push tuntun kan
  (ààyè pending náà ṣì ń pa ìrọ̀rùn ọ̀pọ̀lọpọ̀ run pọ̀). `tests/unit/build/runner-capacity-routing.test.ts`
  fi routing, switch webpack àti pé kò sí ohun kankan lórí `omni-release` tó ń kọ́ pẹ̀lú Turbopack múlẹ̀.
- **Pool fẹ́ẹ́rẹ́fẹ́: `omni-light`.** `omniroute-113` àti `omniroute-113-2` ń ṣiṣẹ́ àwọn nightly tó nílò
  `next build` backend-nìkan (~5–6 GB; webpack) àti `quality.yml` `lint-guard`. `omniroute-113`
  ní `MemoryHigh=4G` títí di 2026-10-18 — ìkọ́lé promptfoo fi reclaim gba ọ̀nà rẹ̀ kọjá ìṣẹ́jú 54
  níbẹ̀; 8 GB yọ throttling náà kúrò.
- **Listeners díẹ̀ pẹ̀lú ète.** A disable unit OmniRoute mẹ́rin ní 2026-08-29 — listener àfikún
  kọ̀ọ̀kan jẹ́ tenant mìíràn fún memory budget tó wà lókè. Òpin janitor jẹ́ 6 (`MAX_ACTIVE_RUNNERS=6` nínú cron): ó ka
  gbogbo `Runner.Listener` lórí ẹ̀rọ náà, OmniHeuris + OmniMind sì fi méjì kún mẹ́rin tiwa.
- **Má ṣe clean `/tmp` tàbí `_work` pẹ̀lú ọwọ́ nígbà tí runner èyíkéyìí bá dí.**
  Check-then-delete tó ní àlàfo láàárín àwọn ìgbésẹ̀ méjèèjì ni ó mú kí job Build tó ń ṣiṣẹ́
  pàdánù `_work` rẹ̀ ní 2026-08-27. Janitor náà ń ṣe check àti removal ní ìgbésẹ̀ kan;
  fi sílẹ̀ fún un.
- Dídá runner dúró láàárín job máa ń cancel job náà (a rí i ṣẹlẹ̀ ní tààrà): lo `systemctl stop`
  nígbà tí listener rẹ̀ kò bá ní child `Runner.Worker` nìkan — kí o sì ṣe é nínú command kan.
- Àwọn workflow kò gbọ́dọ̀ fi artifact sí `/tmp` (RAM ni). Download sí
  `$RUNNER_TEMP` (lórí disk, fún runner kọ̀ọ̀kan) — artifact `next-build` 1.3 GB náà gba ìṣẹ́jú
  27–32 láti dé sórí tmpfs àti ìṣẹ́jú 2 láti upload láti disk.
- VPS `.15` jẹ́ ti homologation nìkan — kò gbọdọ̀ ṣiṣẹ́ CI runners láé.

## Ọ̀nà tí a gbàlejò (àwọn runner tí GitHub gbàlejò)

Àkọọ́lẹ̀ náà wà lórí ètò **Pro**: **àwọn iṣẹ́ gbígbàlejò 40 tó lè ṣiṣẹ́ lẹ́ẹ̀kan náà**, tí gbogbo àyẹ̀wò PR,
gbogbo workflow tí push bá mú ṣiṣẹ́ àti ètò àkọ́kọ́ CodeQL ń pín. Nígbà tí a wọn án ní 2026-10-18 lákòókò
ìpolongo merge kan (~10 merges/hour lórí `release/v3.8.52`): **ìṣiṣẹ́ workflow 2,500 ni a ṣẹ̀dá láàárín
24 h**, push 44 sí branch náà láàárín 6 h, **àwọn iṣẹ́ gbígbàlejò 106 ló wà ní queue** nígbà tí àwọn àyẹ̀wò PR dúró fún
ọ̀pọ̀ wákàtí, tí a sì merge àwọn PR láìsí wọn. Workflow mẹ́sàn-án ló máa ń ṣiṣẹ́ ní gbogbo push sí branch náà:

`tests/unit/build/push-storm-diet.test.ts` fi trigger push ti `ci.yml` àti

**Agbára runner tí a gbàlejò fúnra wa tó pọ̀ síi kò lè tún queue gbígbàlejò náà ṣe.** Devbox náà
(`devbox-vm-06-dev002`, 24 vCPU / 54 GB) lè gbàlejò runner kan, ṣùgbọ́n àwọn session agent ti ń
mú load rẹ̀ wà ní 20–26, container agent náà kò ní daemon Docker, ọ̀nà tí ó sì ti kún jù
ni ọ̀nà gbígbàlejò náà. Ẹ̀rọ `.113` ní 71 GB tó ṣì ṣófo, load rẹ̀ sì wà ní 5–8 ní àkókò kan náà; ohun tó
dí i lọ́wọ́ ni ààlà memory fún listener kọ̀ọ̀kan tó wà lókè (òpó òkè listener 6), kì í ṣe CPU. Àwọn ọ̀nà
tó ṣẹ́kù jẹ́ ti ìlànà iṣẹ́: merge àwọn PR ìpolongo nípasẹ̀ queue Mergify (`label=queue`, àwọn batch ń pín

ètò àkọ́kọ́ CodeQL kù, kí o sì fi àwọn fáìlì tí `release-acceptance.yml` ń kà ṣe filter rẹ̀.
