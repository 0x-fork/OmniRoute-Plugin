## ដំឡើងកម្មវិធីសម្អាត (តែម្តងប៉ុណ្ណោះ នៅលើម៉ាស៊ីន)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root)៖ រៀងរាល់ 30 នាទី កត់ត្រាទៅ /var/log/runner-janitor.log
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

តម្រូវឱ្យមាន `lsof`៖ កម្មវិធីសម្អាតផ្ទៀងផ្ទាត់ថា path មួយទំនេរ ដោយថតស្ថានភាពឯកសារដែលកំពុងបើកតែម្តង មុននឹងលុបវា ហើយបើគ្មានឧបករណ៍នេះ វានឹងមិនលុបអ្វីឡើយ និងជូនដំណឹងអំពីបញ្ហានេះ (exit 1)។ សាកល្បងការផ្លាស់ប្តូរណាមួយជាមួយ `--dry-run` ជាមុន — វាបង្ហាញយ៉ាងច្បាស់នូវអ្វីដែលវានឹងធ្វើ ហើយមិនប៉ះពាល់អ្វីឡើយ។

អ្វីដែលវាធ្វើរាល់ពេលដំណើរការ៖ សម្អាតសំណល់របស់យើងផ្ទាល់ (`runner-*`, `omniroute-*`, `next-build*`, `e2e-build.tar.gz`) បន្ទាប់ពី **3 ម៉ោងនៅលើ tmpfs** និង 24 ម៉ោងនៅលើថាសក្នុង `_work/_temp`; បញ្ឈប់ `next-build` ដែលចាស់ជាង 75 នាទី (គ្មាន job ណាមួយដំណើរការយូរបែបនេះទេ — នៅថ្ងៃទី 2026-08-27 មានមួយបានដំណើរការ 70 នាទី បន្ទាប់ពី GitHub បានប្រកាសថា job របស់វាបាត់បង់); សម្អាត checkout ដែលចាស់ជាង 48 ម៉ោងរបស់ runner ដែល unit របស់វា **បានឈប់**; ជូនដំណឹងពេលថាស ≥ 85 %, memory PSI `full/avg60` ≥ 10 % និងពេលមាន listener ច្រើនជាង `MAX_ACTIVE_RUNNERS` (ជាមួយការបែងចែកជា omniroute/ផ្សេងទៀត)។ Exit 1 = ត្រូវការការយកចិត្តទុកដាក់; សូមអាន log។
