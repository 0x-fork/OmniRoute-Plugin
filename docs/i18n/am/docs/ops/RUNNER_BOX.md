## ማጽጃውን ይጫኑ (አንድ ጊዜ፣ በማሽኑ ላይ)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root)፦ በየ30 ደቂቃው፣ ሎጉን ወደ /var/log/runner-janitor.log ይጻፍ
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

`lsof` ያስፈልጋል፦ ማጽጃው አንድን ዱካ ከማስወገዱ በፊት ክፍት የሆኑ
ፋይሎችን አንድ ጊዜ በመመልከት ሥራ ፈት መሆኑን ያረጋግጣል፤ መሣሪያው ከሌለ
ምንም አያስወግድም፣ ይህንንም ይገልጻል (exit 1)። ማንኛውንም ለውጥ መጀመሪያ
በ`--dry-run` ይሞክሩ — ምን እንደሚያደርግ በትክክል ያትማል፣ ምንም አይነካም።

በእያንዳንዱ አሂድ የሚያደርገው፦ የራሳችንን ቀሪዎች (`runner-*`፣ `omniroute-*`፣
`next-build*`፣ `e2e-build.tar.gz`) **በtmpfs ላይ ከ3 ሰዓት** እና በዲስክ

## የሩጫ አስኪያጅ ዩኒቶች፦ KillMode

የሩጫ አስኪያጁ ነባሪ `KillMode=process` አንድ ዩኒት ሲቆም ወይም እንደገና ሲጀመር
`Runner.Worker → npm → next-build`ን በሕይወት ይተዋል — ወላጅ አልባው build ምንም
የተያያዘ የሥራ ሂደት ሳይኖረው RAM እና CPU መጠቀሙን ይቀጥላል። እያንዳንዱ
