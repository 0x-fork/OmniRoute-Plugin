ಇವೆ (ಹಿಂದಿನ ಮೌಲ್ಯಗಳನ್ನು `override.conf.bak-20261018` ಆಗಿ ಉಳಿಸಲಾಗಿದೆ) ಮತ್ತು
`systemctl set-property --runtime … MemoryHigh=… MemoryMax=… CPUQuota=…` ಮೂಲಕ ಲೈವ್ ಆಗಿ ಅನ್ವಯಿಸಲಾಗಿದೆ — ಮರುಪ್ರಾರಂಭ ಮಾಡಿಲ್ಲ, ಆದ್ದರಿಂದ
ಚಾಲನೆಯಲ್ಲಿದ್ದ ಯಾವುದೇ ಜಾಬ್ಗೆ ತೊಂದರೆಯಾಗಿಲ್ಲ. ಲೇಬಲ್ಗಳನ್ನು ರನ್ನರ್ಗಳ API ಮೂಲಕ
(`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`) ಲೈವ್ ಆಗಿಯೇ ಬದಲಾಯಿಸಲಾಗುತ್ತದೆ.

## ಜ್ಯಾನಿಟರ್ ಅನ್ನು ಸ್ಥಾಪಿಸಿ (ಒಂದು ಬಾರಿ, ಯಂತ್ರದಲ್ಲಿ)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): ಪ್ರತಿ 30 ನಿಮಿಷಕ್ಕೊಮ್ಮೆ, /var/log/runner-janitor.log ಗೆ ಲಾಗ್ ಮಾಡಿ
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

`lsof` ಅಗತ್ಯವಿದೆ: ಜ್ಯಾನಿಟರ್ ತೆಗೆದುಹಾಕುವ ಮೊದಲು ತೆರೆದಿರುವ ಫೈಲ್ಗಳ ಒಂದು ಸ್ನ್ಯಾಪ್ಶಾಟ್ ಮೂಲಕ ಪಾತ್ ನಿಷ್ಕ್ರಿಯವಾಗಿದೆ ಎಂಬುದನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ; ಈ ಟೂಲ್ ಇಲ್ಲದಿದ್ದರೆ ಅದು ಏನನ್ನೂ ತೆಗೆದುಹಾಕುವುದಿಲ್ಲ ಮತ್ತು ಹಾಗೆಂದು ತಿಳಿಸುತ್ತದೆ
(exit 1). ಯಾವುದೇ ಬದಲಾವಣೆಯನ್ನು ಮೊದಲು `--dry-run` ನೊಂದಿಗೆ ಪ್ರಯತ್ನಿಸಿ — ಅದು ಏನು ಮಾಡಲಿದೆ ಎಂಬುದನ್ನು ನಿಖರವಾಗಿ ಮುದ್ರಿಸುತ್ತದೆ
ಮತ್ತು ಯಾವುದನ್ನೂ ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

ಪ್ರತಿ ರನ್ನಲ್ಲಿ ಅದು ಮಾಡುವುದೇನೆಂದರೆ: ನಮ್ಮದೇ ಉಳಿಕೆಗಳನ್ನು (`runner-*`, `omniroute-*`,
`next-build*`, `e2e-build.tar.gz`) **tmpfs ನಲ್ಲಿ 3 ಗಂ.** ಮತ್ತು ಡಿಸ್ಕ್ನ
`_work/_temp` ನಲ್ಲಿ 24 ಗಂ. ಕಳೆದ ನಂತರ ತೆರವುಗೊಳಿಸುತ್ತದೆ; 75 ನಿಮಿಷಕ್ಕಿಂತ ಹಳೆಯದಾದ `next-build` ಅನ್ನು ಸ್ಥಗಿತಗೊಳಿಸುತ್ತದೆ (ಯಾವುದೇ ಜಾಬ್ ಅಷ್ಟು ಹೊತ್ತು ರನ್ ಆಗುವುದಿಲ್ಲ —
2026-08-27 ರಂದು GitHub ಅದರ ಜಾಬ್ ನಷ್ಟವಾಗಿದೆ ಎಂದು ಘೋಷಿಸಿದ ನಂತರವೂ ಒಂದು ಜಾಬ್ 70 ನಿಮಿಷ ರನ್ ಆಗಿತ್ತು); ಯೂನಿಟ್ **ನಿಲ್ಲಿಸಲಾದ** ರನ್ನರ್ಗಳ 48 ಗಂ. ಹಳೆಯ
ಚೆಕ್ಔಟ್ಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ; ಡಿಸ್ಕ್ ≥ 85 %, ಮೆಮೊರಿ PSI
`full/avg60` ≥ 10 %, ಮತ್ತು `MAX_ACTIVE_RUNNERS` ಗಿಂತ ಹೆಚ್ಚು ಲಿಸನರ್ಗಳಿದ್ದಾಗ (omniroute/ಇತರೆ
ವಿಭಜನೆಯೊಂದಿಗೆ) ಎಚ್ಚರಿಸುತ್ತದೆ. Exit 1 = ಗಮನ ಅಗತ್ಯ; ಲಾಗ್ ಓದಿ.

## ರನ್ನರ್ ಯೂನಿಟ್ಗಳು: KillMode

ರನ್ನರ್ನ ಡೀಫಾಲ್ಟ್ `KillMode=process`, ಯೂನಿಟ್ ಅನ್ನು ನಿಲ್ಲಿಸಿದಾಗ ಅಥವಾ ಮರುಪ್ರಾರಂಭಿಸಿದಾಗ `Runner.Worker → npm → next-build`
ಅನ್ನು ಚಾಲನೆಯಲ್ಲೇ ಬಿಡುತ್ತದೆ — ಯಾವುದೇ ಜಾಬ್ಗೆ ಲಗತ್ತಾಗಿರದ ಅನಾಥ ಬಿಲ್ಡ್ RAM ಮತ್ತು
CPU ಅನ್ನು ಬಳಸುತ್ತಲೇ ಇರುತ್ತದೆ. ಪ್ರತಿ OmniRoute ಯೂನಿಟ್ಗೂ
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
ನಲ್ಲಿ `KillMode=mixed` ಇರುವ ಡ್ರಾಪ್-ಇನ್ ಇದೆ: ಮೊದಲು listener ಗೆ SIGTERM, ನಂತರ
`TimeoutStop` ಸಮಯದಲ್ಲಿ ಸಂಪೂರ್ಣ cgroup ಗೆ SIGKILL. ಯೂನಿಟ್ನ ಮುಂದಿನ ಮರುಪ್ರಾರಂಭದಲ್ಲಿ ಇದು
ಜಾರಿಗೆ ಬರುತ್ತದೆ — **ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ರನ್ನರ್ ಅನ್ನು, ಅದು ನಿಷ್ಕ್ರಿಯವಾಗಿದ್ದಾಗ ಮಾತ್ರ** ಮರುಪ್ರಾರಂಭಿಸಿ,
ನಿಷ್ಕ್ರಿಯತೆ ಪರಿಶೀಲನೆ ಮತ್ತು ಮರುಪ್ರಾರಂಭ ಎರಡನ್ನೂ ಒಂದೇ ಕಮಾಂಡ್ನಲ್ಲಿ ಮಾಡಿ.
