(`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`), ਉਹ ਵੀ ਚੱਲਦੇ ਸਿਸਟਮ ਉੱਤੇ ਹੀ।

## ਜੈਨਿਟਰ ਇੰਸਟਾਲ ਕਰੋ (ਇੱਕ ਵਾਰ, ਬਾਕਸ ਉੱਤੇ)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): ਹਰ 30 ਮਿੰਟ ਬਾਅਦ, /var/log/runner-janitor.log ਵਿੱਚ ਲੌਗ ਕਰੋ
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

`lsof` ਲੋੜੀਂਦਾ ਹੈ: ਜੈਨਿਟਰ ਕਿਸੇ ਪਾਥ ਨੂੰ ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਖੁੱਲ੍ਹੀਆਂ
ਫ਼ਾਈਲਾਂ ਦੇ ਇੱਕ ਸਨੈਪਸ਼ਾਟ ਨਾਲ ਇਹ ਸਾਬਤ ਕਰਦਾ ਹੈ ਕਿ ਉਹ ਨਿਸ਼ਕਿਰਿਆ ਹੈ, ਅਤੇ ਇਸ ਟੂਲ ਤੋਂ ਬਿਨਾਂ
ਇਹ ਕੁਝ ਵੀ ਨਹੀਂ ਹਟਾਉਂਦਾ ਅਤੇ ਇਸ ਬਾਰੇ ਦੱਸਦਾ ਹੈ
(exit 1)। ਕਿਸੇ ਵੀ ਤਬਦੀਲੀ ਨੂੰ ਪਹਿਲਾਂ `--dry-run` ਨਾਲ ਅਜ਼ਮਾਓ — ਇਹ ਬਿਲਕੁਲ ਉਹੀ ਪ੍ਰਿੰਟ ਕਰਦਾ ਹੈ ਜੋ ਇਹ
ਕਰੇਗਾ ਅਤੇ ਕਿਸੇ ਚੀਜ਼ ਨੂੰ ਛੂੰਹਦਾ ਨਹੀਂ।

ਹਰ ਰਨ ਦੌਰਾਨ ਇਹ ਕੀ ਕਰਦਾ ਹੈ: **tmpfs ਉੱਤੇ 3 ਘੰਟਿਆਂ** ਅਤੇ ਡਿਸਕ
`_work/_temp` ਉੱਤੇ 24 ਘੰਟਿਆਂ ਬਾਅਦ ਸਾਡੀਆਂ ਆਪਣੀਆਂ ਬਚੀਆਂ ਚੀਜ਼ਾਂ (`runner-*`, `omniroute-*`,
`next-build*`, `e2e-build.tar.gz`) ਸਾਫ਼ ਕਰਦਾ ਹੈ; 75 ਮਿੰਟਾਂ ਤੋਂ ਪੁਰਾਣੇ `next-build` ਨੂੰ ਬੰਦ ਕਰਦਾ ਹੈ (ਕੋਈ ਜੌਬ ਇੰਨੀ ਦੇਰ ਨਹੀਂ ਚੱਲਦੀ —
2026-08-27 ਨੂੰ GitHub ਵੱਲੋਂ ਉਸਦੀ ਜੌਬ ਗੁਆਚੀ ਹੋਈ ਘੋਸ਼ਿਤ ਕਰਨ ਤੋਂ ਬਾਅਦ ਵੀ ਇੱਕ 70 ਮਿੰਟ ਤੱਕ ਚੱਲਦੀ ਰਹੀ); ਉਹਨਾਂ ਰਨਰਾਂ ਦੇ 48 ਘੰਟੇ ਪੁਰਾਣੇ
ਚੈਕਆਉਟ ਹਟਾਉਂਦਾ ਹੈ ਜਿਨ੍ਹਾਂ ਦੀ ਯੂਨਿਟ **ਬੰਦ** ਹੈ; ਡਿਸਕ ≥ 85 %, ਮੈਮੋਰੀ PSI
`full/avg60` ≥ 10 %, ਅਤੇ `MAX_ACTIVE_RUNNERS` ਤੋਂ ਵੱਧ ਲਿਸਨਰਾਂ ਉੱਤੇ ਅਲਰਟ ਕਰਦਾ ਹੈ (ਇੱਕ
omniroute/ਹੋਰ ਵੰਡ ਸਮੇਤ)। Exit 1 = ਧਿਆਨ ਦੇਣ ਦੀ ਲੋੜ ਹੈ; ਲੌਗ ਪੜ੍ਹੋ।

## ਰਨਰ ਯੂਨਿਟਾਂ: KillMode

ਰਨਰ ਦਾ ਡਿਫਾਲਟ `KillMode=process`, ਕਿਸੇ ਯੂਨਿਟ ਨੂੰ ਰੋਕਣ ਜਾਂ ਮੁੜ-ਚਾਲੂ ਕਰਨ ਵੇਲੇ `Runner.Worker → npm → next-build`
ਨੂੰ ਚੱਲਦਾ ਛੱਡ ਦਿੰਦਾ ਹੈ — ਇੱਕ ਅਨਾਥ ਬਿਲਡ ਬਿਨਾਂ ਕਿਸੇ ਜੌਬ ਨਾਲ ਜੁੜੇ RAM ਅਤੇ
CPU ਵਰਤਦਾ ਰਹਿੰਦਾ ਹੈ। ਹਰ OmniRoute ਯੂਨਿਟ ਵਿੱਚ ਇੱਕ ਡਰੌਪ-ਇਨ
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
ਹੈ, ਜਿਸ ਵਿੱਚ `KillMode=mixed` ਹੈ: ਪਹਿਲਾਂ ਲਿਸਨਰ ਨੂੰ SIGTERM, ਫਿਰ
`TimeoutStop` ਉੱਤੇ ਪੂਰੇ cgroup ਨੂੰ SIGKILL। ਇਹ ਯੂਨਿਟ ਦੇ ਅਗਲੇ ਮੁੜ-ਚਾਲੂ ਹੋਣ ਉੱਤੇ ਪ੍ਰਭਾਵੀ ਹੁੰਦਾ ਹੈ — ਇੱਕ ਸਮੇਂ
**ਸਿਰਫ਼ ਇੱਕ ਰਨਰ ਮੁੜ-ਚਾਲੂ ਕਰੋ, ਅਤੇ ਕੇਵਲ ਉਦੋਂ ਜਦੋਂ ਉਹ ਨਿਸ਼ਕਿਰਿਆ ਹੋਵੇ**, ਨਿਸ਼ਕਿਰਿਆਤਾ ਦੀ ਜਾਂਚ ਅਤੇ ਮੁੜ-ਚਾਲੂ ਕਰਨਾ ਇੱਕੋ ਕਮਾਂਡ ਵਿੱਚ ਕਰੋ।
